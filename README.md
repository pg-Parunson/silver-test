# 주얼리 제품 관리 모의시험

NCS 과정평가 대비 개인 학습용 모의시험 웹앱.

- **출제 범위**: NCS 학습모듈 「주얼리 제품 관리」(LM2202020611_16v3) 중 시험 범위로 지정된 부분
- **구성**: 객관식 16문항 + 주관식 4문항 = 20문항 (문항당 5점, 100점 만점)
- **시험 시간**: 60분 — 시간 종료 시 자동 제출
- **기능**: 매번 문제은행에서 새로 출제(선지 순서 셔플), 자동 채점, 문항별 해설, 주관식 자가 채점 보정, 응시 기록(브라우저 저장), 새로고침 시 진행 중 시험 복구
