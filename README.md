# 귀금속가공기능사 모의시험

NCS 과정평가 대비 개인 학습용 모의시험 웹앱.

- **출제 범위**: 귀금속가공기능사(과정평가형) 필기 7개 능력단위 — 왁스카빙 · 조립가공 · 가공안전관리 · 펜던트세공 · 기초조각 · 솔더링/버프연마 · 주얼리 제품 관리
- **문제은행**: 350문항 (객관식 280 · 주관식 70)
- **구성**: 객관식 16문항 + 주관식 4문항 = 20문항 (문항당 5점, 100점 만점) — 주관식 20문항만 푸는 유형도 있다
- **시험 시간**: 60분 — 시간 종료 시 자동 제출
- **기능**: 매번 문제은행에서 새로 출제(선지 순서 셔플, 정답이 겹치는 문항은 한 시험지에 함께 내지 않음), 자동 채점, 문항별 해설, 주관식 자가 채점 보정, 응시자 순위(Supabase 공유), 응시 기록(브라우저 저장), 새로고침 시 진행 중 시험 복구, 시간·점수 없이 푸는 학습 모드

## 과목

과목마다 문제은행과 순위표가 따로 있다. `app.js`의 `SUBJECTS`에 등록하며,
`hidden: true`를 붙이면 데이터와 순위 기록은 그대로 둔 채 표지에서만 내려간다.

- `metalwork` — 귀금속가공기능사 (350문항)
- `jewelry` — 주얼리 제품 관리 (224문항, 시험이 끝나 현재 숨김)

## 실행

정적 사이트라 서버가 필요 없다. `index.html`을 열거나 아무 정적 호스팅에 올리면 된다.
순위표만 Supabase를 쓰며, `config.js`가 없으면 브라우저 저장소로 대체된다.
